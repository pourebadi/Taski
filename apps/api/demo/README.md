# پوشه demo — فقط برای بازرسی و دمو

این پوشه بخشی از محصول نیست. یک سرور سبک است که همان سرویس‌های واقعی را
روی یک هارنس `node:sqlite` اجرا می‌کند، برای وقتی که موتور پریسما در دسترس نیست.

روی ماشین شما به این پوشه نیاز ندارید؛ از `npm run dev` استفاده کنید.
اگر خواستید اجرا کنید، ابتدا سرویس‌ها را کامپایل کنید (راهنما در `docs/05-audit-report.md`).
