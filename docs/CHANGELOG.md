## [Unreleased] — بازطراحی UX و دیزاین (برنچ redesign/ux-and-design-overhaul)

### مرحله ۳ — بازطراحی حالت‌های کامپوننت‌ها
- گسترش کامل توکن‌های کامپوننت AntD برای همه‌ی حالت‌ها در هر دو تم:
  - دکمه‌ها: hover/active/focus، سایه‌ی ملایم primary، حالت پیش‌فرض با مرز برند در hover
  - ورودی‌ها/InputNumber/Select/DatePicker: مرز hover برند، مرز active، هاله‌ی فوکوس برند، حالت غیرفعال
  - Select/Dropdown/Menu: پس‌زمینه‌ی hover و انتخاب‌شده‌ی برند، پنل روی سطح elevated
  - Table: هدر، hover ردیف برند، مرز نرم، فاصله‌ی سلول؛ Tabs با نوار برند؛ Segmented/Tag/Alert/Tooltip/Skeleton هماهنگ
- توکن‌های تعامل مشترک (`controlItemBgHover/Active`, `controlOutline`, `colorBgTextHover`, غیرفعال) برای یکدستی
- CSS: نشانگر ماوس روی ردیف‌های کلیک‌پذیر، برجسته‌شدن کارت هنگام focus-within (پیمایش کیبورد)
- بررسی بصری زنده در هر دو تم با بک‌اند ماک محلی (dropdown، فوکوس، دراور، جدول، بج‌ها)

### مرحله ۲ — زبان و مفاهیم
- `lib/terms.ts`: تک منبع واژگان دامنه (مرحله، اولویت، سلامت، جریان، نوع کار، علت، اطمینان، نقش، نقش‌های روی کار) با فارسی + انگلیسی + رنگ + توضیح
- **بازتعریف اولویت**: به‌جای «P0» خام، «فوری · P0 / مهم · P1 / عادی · P2 / کم · P3» — کد هرگز تنها نمی‌آید
- انگلیسی داخل پرانتز در Selectها و برچسب‌ها (dual)؛ رفع تکرار برچسب نقش در دو فایل
- بازنویسی مرحله‌ها: «آماده» → «آماده شروع (Ready)»، «در بازبینی» → «منتظر تأیید (Review)»؛ سلامت: «مسدود» → «متوقف»، علت‌ها به جمله‌ی کامل
- سه نقش روی کار شفاف شد: مسئول (Owner) / مجری (Assignee) / تأییدکننده (Reviewer) با تعریف واحد
- رفع FE-6: تب‌های تصویر کلی دیگر روی رشته‌ی فارسی کلید نمی‌خورند (شناسه‌ی پایدار org/planning/team)
- `tf()` برای جای‌گذاری متغیر؛ تست `terms-sync.test.ts` که واگرایی terms.ts ↔ fa.json را قرمز می‌کند
- ۱۷۵ تست وب (+۲۳) و ۱۵۲ تست API، همه سبز

### مرحله ۱ — بنیان دیزاین + دارک‌مود
- تک منبع حقیقتِ رنگ در `theme/tokens.ts` (روشن + تیره)؛ سه سیستم رنگ ناسازگار قبلی (theme.ts / styles.css / رنگ‌های هاردکد) یکی شد
- افزودن تمِ تیره‌ی کامل با `ThemeProvider`: پیروی از سیستم یا انتخاب دستی، ذخیره در localStorage، تزریق پیش‌از‌رندر برای جلوگیری از پرشِ تم
- دکمه‌ی تغییر تم در هدر
- `styles.css`: بلاک `:root` روشن + `[data-theme="dark"]`؛ کارت‌ها و ستون‌های بورد با سایه و مرز نرم جدا می‌شوند نه خط پررنگِ وایرفریمی
- رفع باگ رنگ نامعتبر `var(--warn)33` در دراور؛ توکنی‌کردن آیکون‌های راهنمای هاردکد
- تست جدید `theme-sync.test.ts` (۶۸ بررسی) که واگرایی tokens.ts ↔ styles.css را قرمز می‌کند
- فعال‌سازی اجرای تست‌های فرانت (jsdom/vitest/testing-library به devDeps اضافه شد)؛ `npm test` حالا هر دو سمت را اجرا می‌کند — ۱۵۲ تست API + ۱۵۲ تست وب، همه پاس
